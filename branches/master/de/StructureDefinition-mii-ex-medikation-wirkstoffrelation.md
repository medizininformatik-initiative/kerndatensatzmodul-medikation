## Extension: MII EX Medikation Wirkstoffrelation 

| | |
| :--- | :--- |
| *Offizielle URL*:https://www.medizininformatik-initiative.de/fhir/core/modul-medikation/StructureDefinition/wirkstoffrelation | *Version*:2027.0.0-ballot.rc5 |
| Active Stand: 2024-11-14 | *Maschinenlesbarer Name*:MII_EX_Medikation_Wirkstoffrelation |

Die Extension ermöglicht die Zuordnung von einem genauem Wirkstoff (z.B. Salz, Ester) zu einem allgemeinem Wirkstoff.

**Context of Use**

### Inhalt

Die Extension Wirkstoffrelation erlaubt es, Referenzen zwischen den Wirkstoffen abzubilden. Somit KANN ein Wirkstoff, der als "genauer" Wirkstoff klassifiziert ist, eindeutig einem "allgemeinen" Wirkstoff zugeordnet werden. Dies erlaubt bspw. die Umrechnung, dass "10mg Bisoprolol hemifumarat" "8,49mg Bisoprolol" entsprechen.
